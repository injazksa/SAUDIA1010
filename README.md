# إنجاز السعودية — موقع مكتب تأشيرات السعودية في الأردن

موقع ثابت (HTML وCSS وJavaScript) يُنشر على Netlify من هذا المستودع.

- **الموقع:** https://saudia-visa.com
- **الإصدار:** 2026.11.5 (5/11/2026). التفاصيل في `RELEASE-NOTES.md` و`CHANGELOG.md`.

## محتويات المستودع

| المسار | ما هو |
|---|---|
| `frontend/public/` | **الموقع كاملًا.** هذا ما ينشره Netlify: الصفحات، و1,120 صفحة مهن ودلائل في `p/`، والمدونة، والإنجليزية، والصور، والخطوط، والسكربتات |
| `frontend/public/_redirects` | تحويلات 301 للروابط القديمة |
| `frontend/public/_headers` | رؤوس الأمان والتخزين المؤقت |
| `netlify.toml` | إعدادات Netlify: مجلد النشر، أمر البناء، تحويلات إضافية |
| `scripts/ai-files.mjs` | يولّد ملفات الذكاء الاصطناعي (`llms.txt` و`llms-full.txt` و`llms-professions.txt` و`ai.txt`) من الصفحات عند كل بناء |
| `scripts/ai-facts.json` | معلومات المكتب لملفات الذكاء الاصطناعي، منقولة من الصفحات الظاهرة. **عدّل هنا** عند تغيّر الهاتف أو الدوام أو الخدمات |
| `scripts/ai-files-state.json` | تاريخ آخر تغيير لكل ملف ذكاء اصطناعي |
| `scripts/sitemap.mjs` | يولّد خرائط الموقع (Sitemap) تلقائيًا عند كل بناء |
| `scripts/sitemap-state.json` | سجل تاريخ آخر تغيير لنص كل صفحة (يُستخدم في `lastmod`) |
| `scripts/seo-check.mjs` | فحص SEO قبل النشر: يوقف البناء عند خطأ جسيم |
| `scripts/serve.mjs` | معاينة الموقع محليًا دون أي حزم |
| `scripts/check-live.mjs` | فحص بعد النشر لما يرسله Netlify فعلًا (تخزين، أنواع ملفات، تحويلات) |
| `docs/` | أدلة التحديث والنشر وتقرير الاختبار والمقارنة بالنسخة السابقة |

## التشغيل محليًا

**المطلوب:** Node.js 18 أو أحدث. لا توجد حزم تُثبَّت، و`npm install` لا يفعل شيئًا.

```bash
npm run build
```

يولّد ملفات الذكاء الاصطناعي، ثم خرائط الموقع، ثم يفحص SEO. وهو نفس ما يشغّله Netlify.

```bash
npm start
```

يفتح الموقع على http://localhost:8080.

**لمطابقة Netlify تمامًا** (كل قواعد التحويل والرؤوس)، استخدم أداة Netlify الرسمية:

```bash
npx netlify-cli serve
```

## إضافة محتوى جديد

راجع `docs/ADDING-CONTENT.md`. باختصار:
- أضف الصفحة داخل `frontend/public/`، مع العنوان والوصف وcanonical؛
- خريطة الموقع وملفات الذكاء الاصطناعي تُحدَّث وحدها عند النشر؛
- الفحص يمنع النشر إن كان في الصفحة خطأ جسيم.
